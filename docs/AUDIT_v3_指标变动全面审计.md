## 一、民心（morale）

### 1.1 月度结算（settlement_metrics.py:213-241）

| 因素 | 公式 | 月均影响 | 说明 |
|------|------|----------|------|
| 基础衰减 | -1.0 × zone_mult | -0.4 ~ -1.5 | Low(0-35)×0.4, Mid(35-65)×1.0, High(65+)×1.5 |
| 文教加成 | +(edu-30)/40 | 0 ~ +1.75 | edu>30时生效，edu=100→+1.75 |
| 治安联动 | +(sec-50)/40 | -1.25 ~ +1.25 | 连续渐变，sec=0→-1.25, sec=100→+1.25 |
| 重税惩罚 | -1.0 | -1.0 | tax_rate ≥ 0.15 |

**均衡点分析**：

- 高民心区（65+）：衰减 -1.5，需 edu≥60 且 sec≥70 才能勉强持平
- 中民心区（35-65）：衰减 -1.0，edu=50+sec=50 → 净变 -0.5/月
- 低民心区（0-35）：衰减 -0.4，自然回升容易

### 1.2 司法判决（judicial_caseflow.py:326-348）⚠️

| 触发 | 效果 | 频率 | 月均影响 |
|------|------|------|----------|
| 每个判决（重判路线） | morale +2（clamped） | 3案/3月 | **+2.0/月** |
| 每个判决（轻判路线） | morale +1~+2（clamped） | 同上 | **+1.0~+2.0/月** |
| 搁置案件 | morale 0 | — | 0 |

> **⚠️ 问题**：3案/季度（`CASES_PER_WINDOW=3`），JSON数据中大部分"重判"选项morale=3~12（均clamped到+2），"轻判"morale=1~3（clamped到+2）。只要玩家积极判案，每季度稳定获得 +4~6 民心，折算月均 +1.3~2.0。这使得月度衰减几乎被完全抵消，民心难以下降。
>
> security 同理：重判路线 security +2/案（clamped），3案/季 → 月均 +2.0。

## ⚠️ 审计发现与建议

### 问题1（严重）：司法判决系统性抬高民心和治安

**现状**：
- `CASES_PER_WINDOW = 3`，每季度3案
- JSON数据中 195个判决选项，102个有 morale>0（绝大多数原始值3~12，全部clamped到+2）
- security同理，84个有 security>0
- 玩家只要判案（不搁置），**每季度稳定获得 morale +4~6、security +4~6**
- 折算月均：morale **+1.3~2.0/月**，security **+1.3~2.0/月**

**影响**：
- 月度衰减（morale -1.0, security -1.2 在中区）几乎被完全抵消
- 民心和治安长期趋势向上，丧失了"管理压力"的核心玩法张力
- 与所有负面事件（灾害、兼并、隐田）的惩罚效果被大幅稀释

**建议方案**（按侵入性从低到高）：

**A. 降低 clamp 上限**：morale/security 从 ±2 降为 ±1
- 优点：最小改动，月均影响从 +2 降到 +1
- 缺点：玩家感知"判案没什么用"，且+1仍显著

**B. 改为"总量池"机制**：每季度司法 morale/security 总增益设上限（如 +3）
- 3案共享 +3 额度，而非每案独立 +2
- 优点：保留"公正判案有回报"的体验，但总量可控

**C. 改为"仅负面有效"**：正确判决不加民心，错误判决扣民心
- 即判案是"维护"治安而非"提升"
- 优点：最符合历史——司法是基本职责，做好是应该的
- 缺点：玩家激励不足

**D. 区分首次与后续**：同类型案件首次判决全额，重复案件递减
- 缺点：实现复杂

**推荐方案 B**：每季度司法指标池上限 +3（morale和security各自独立），保持判案体验但不膨胀。

### 问题2（中等）：治安衰减被衙役+司法双重对冲

**现状**：
- L3衙役月度加成 +2.01
- 司法月均 +1.3~2.0
- 合计 +3.3~4.0/月，远超基础衰减 -1.2

**影响**：高治安（65+）衰减 -1.8，仍然净增长 +1.5~2.2/月

**建议**：与问题1联动解决。如采用方案B限制司法收益，治安净增量会回落到合理范围。

### 问题3（轻微）：赈灾 morale +8 叠加司法判决，灾年反而更好

当灾害发生且赈灾时：morale -8(灾害) +8(赈灾) +2(秋收补助) = 净+2，加上司法判决，灾年民心可能反升。

**建议**：可接受，不一定需要改。玩家花了80两赈灾，获得正向回报是合理的。但如果司法收益被控制（问题1），灾年就会成为真正的考验。

### 问题4（信息补全）：自创施政（custom policy）的指标效果

自创施政通过 `investment.py:254-265` 的 `apply_stat_delta` 应用效果，支持 morale/security/commercial/education/agriculture_bonus 变化。效果值由LLM提案+省布政使审批决定，无硬编码上限（仅受 [0,100] clamp）。

**风险**：LLM可能生成过大的效果值。

**建议**：在 `apply_stat_delta` 中添加单次变化上限（如 ±10），与司法 clamp 逻辑一致。
