# 治县要略（施政速查）

## 财政时序
- 田赋：**十月**入账，民心越高征收效率越好；高税率（15%）持续侵蚀民心
- 徭役折银：**五月**一次性向自耕农征收，绅衿免役
- 商税：月征，地方留存60%
- 行政开支：**九月**一次性扣除（含所有基建维护费）

## 民心与治安
- 两者每月自然衰减，需主动施政维持
- 文教高→民心缓慢回升；衙役充足→治安稳定
- 治安良好时民心向好；民心低落时治安趋于恶化

## 投资要点
- 可选投资及当前费用见【可选行动】；费用随物价指数浮动
- 水利→减轻洪旱减产；义仓/赈灾→减少灾年人口损失；医馆→降低瘟疫概率
- 道路→提升商业值；村塾→指定村民心+5；县学→文教（民心长期驱动）
- 资金不足时优先赈灾和治安，再考虑长期建设

## 灾害
- **六月前后**检定：洪涝/旱灾/蝗灾/瘟疫
- 洪旱蝗→秋收减产；瘟疫→人口损失（不减产）
- 灾后可申请知府蠲免配额

## 粮食与民变
- 粮储严重不足→粮荒→民心持续下滑→**民变**
- 民变一旦爆发，知府直接介入接管，局势急速恶化
- 应对：借粮邻县、购粮、强征地主（乡绅关系恶化）

## 人口
- 年度自然增长；治安低迷或民心持续低落→人口净流失
- 邻县竞争：民心/治安/商业/文教明显落后→人口外流；明显领先→人口迁入

## 知府关系
- 年度钱粮配额须完成，否则年度考评不利
- 腊月年度评议（优/良/中/差），直接影响仕途升迁
